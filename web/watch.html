Watchlist

Services that matter to you, rechecked on a schedule, so a breach is caught even when nobody is looking.

How the watchlist works

Services on the watchlist are rechecked nightly by an automated run. Any new breach lands in the receipts ledger with its claim by deadline, so the claim window never quietly expires while a claim sits unfiled.

Nightly rechecks run against the public miner at no charge; paid engine purchases are listed separately on the Receipts page.

01

Listed

Watched services live in a public list in the DownProof repo, so anyone can see what is being watched.

02

Rechecked nightly

An automated run rechecks every listed service each night at 02:30 UTC, using the same miner the homepage uses.

03

Recorded

Each result is appended to a public results log in the repo with its date, so the history cannot be quietly rewritten.
